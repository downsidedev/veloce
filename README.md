Veloce, a lightweight browser.

Latest Version: Veloce 5 (Nocciola)
Features of this version:
1. Settings
 | 5 themes for the navigation bar
 | Search Engine change ability
2. Cool Navigation Buttons
3. New downloads window
4. Other quirks

Planned features for Veloce 6 (Arrabiata)
1. Adblock by default
2. New options on settings
3. More not noticable quirks
4. "Quirks", built in extensions that you can disable and turn on, probably will be finished on later releases.

FAQ:

Do old Veloce versions have EOL dates?
I am not sure, this is a new browser project, so EOL might come late.
